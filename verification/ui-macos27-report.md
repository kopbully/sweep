# Sweep 0.6.0 UI 验收记录

日期：2026-10-26。安装路径：/Applications/Sweep.app。

## 界面来源与适配

参考项目：[a2d2-dev/macos27-claude](https://github.com/a2d2-dev/macos27-claude)。

读取了 src/styles/glass.css、src/styles/index.css、src/components/Window.tsx 和 src/apps/finder/index.tsx，并打开公开演示中的 Finder 核对视觉。原始文件的 Git blob SHA 记录在 ui-macos27-result.json。参考项目的 MIT 许可证已放入 Sources/Sweep/Resources/ThirdParty/，随应用打包。

| 参考特征 | Sweep 原生实现 |
| --- | --- |
| 浅色/深色玻璃窗口层次 | NSVisualEffectView 侧栏及工具栏；动态 NSColor 主题 |
| Finder 蓝色选中行 | 蓝底白字导航、原生 SF Symbols、悬停反馈 |
| 清晰内容面、细边框、轻阴影 | 共用 Panel、Card、标签和分段控件 |
| 紧凑工具栏、搜索与操作区 | 模块路径工具栏、清理筛选框、统一按钮比例 |

十个模块仍按空间、系统、记录分组。清理、监控的改动均在视图部分；本轮未调整扫描、删除和采样算法。公共按钮改为 ButtonStyle，按下反馈使用系统按钮状态。

## 验证结果

- Release 打包成功；安装版版本为 0.6.0，签名验证通过，安装版主程序与最终构建 SHA256 一致。
- 现有回归：**123/123 通过**，原始输出见 ui-macos27-regression.txt。
- 配色检查：主要文字、蓝色按钮、侧栏选中态的已列配色均达到 4.5:1；见 ui-macos27-contrast.json。
- 已在原生安装版依次打开十个模块，检查导航状态及控件显示。
- 浅色窗口视觉检查覆盖原有 1240 宽窗口与新建的 **1080×700 内容区**（含标题栏窗口为 1080×732）；监控六张指标卡已统一高度，侧栏十个入口均可见。
- 清理页：默认 0 项已选；搜索无匹配状态正确；推荐选择显示 5 项；打开确认弹窗后执行“取消”，再恢复为全不选；未确认任何真实清理。
- 操作历史：筛选启动项后只显示 2 条对应记录，恢复全部筛选。
- 黑洞：隐藏与恢复按钮状态正确；重启后保持启用；日志出现 BLACKHOLE READY。
- 黑洞控制器、废纸篓逻辑、单实例锁、Web 资源相对修改前 Git HEAD 均无差异；安装包内黑洞资源的哈希与构建资源一致。
- 新建的验收主窗口已关闭，当前保留原主窗口的监控页面，黑洞处于启用状态。
