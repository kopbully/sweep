# Sweep 磁盘清理改进

用户目标：研究 MangoDisk 的清理实现，改进 Sweep 的磁盘清理，保留已验收的桌面黑洞。

1. 固定参考源码与旧版检查点，复现旧清理入口全路径拒绝、默认全选和 Archives/Trash 选择问题。验证：只读源码及自建基线检查，不运行用户缓存清理。
2. 在清理模块独立实现少量规则、范围验证、可取消扫描、权限诊断、去重与执行前重验。验证：临时 fake home 的边界、链接、并发状态、文件变更与逐项结果测试。
3. 改进清理页的进度、取消、推荐选择、明确确认与结果报告。逻辑大小和磁盘占用分别标为估算，扫描不覆盖上次执行结果。验证：构建、状态检查与原生界面交互。
4. 保存旧版后安装更新，核对两个安装位置、签名和源码同步。验证：新构建实际启动、只读扫描可取消、已有黑洞文件与资源哈希保持一致。

范围：保持五模块与黑洞入口；清理使用独立规则策略，避免改动共享 PathSafety/Remover 后意外启用旧维护或卸载分支。只在本次创建的夹具上验证删除；不运行用户缓存清理、清空废纸篓或管理员维护。

参考：`../MangoDisk`，commit `b9199fd3568d60e8d1c2462acfdcc6a723a6cb84`。以源码研究扫描、预检、诊断与逐项结果行为，用 Swift 独立实现，不引入该项目代码、规则库或新运行时。

旧版完整应用与源码：`before-cleanup-0.2.1/`；黑洞必须保持该检查点中 `BlackHole.swift`、`BlackHoleTrash.swift` 与 `Resources/BlackHole` 的原始哈希。
